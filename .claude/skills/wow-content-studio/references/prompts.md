# Mode specs (WOW Production)

## §A · סרט / סצנה
- Length: 15–45 s. Payoff shot inside the first 2 seconds (the most impossible frame first, not a slow intro).
- On-screen hook (sound-off), max 7 words, pattern: "זה לא צולם." / "הבחור הזה לא קיים." / "אף מצלמה לא הייתה כאן."
- Table: זמן | מה רואים | טקסט על המסך | קול / סאונד.
- Caption: line 1 = the hook as a sentence; 2–3 short lines of story; one either/or question; signature; ≤5 hashtags.
- Give 3 alternative hooks.

## §B · מאחורי הקלעים
- Structure: 0–2 s final result → 2–5 s "ככה זה התחיל" (raw: prompt, 3D block, sketch) → 5–25 s 3 steps, one tool per step, each with on-screen label → last 3 s split screen before/after + keyword CTA.
- CTA: "כתבו ״פרומפט״ ואשלח לכם בפרטי את [the specific thing]".
- Also write the DM auto-reply (≤300 chars, warm, includes the promised item placeholder and one soft line about the studio).

## §C · סיפור לקוח
- Never "צרו קשר" alone. Structure: the client's problem (1 line) → the idea → 2–3 frames of the film → the result (real only, else placeholder) → "יש לכם מסר שצריך להפוך לסרט? WhatsApp בביו."
- Ask the client to collab-post (shared post = shared reach).

## §D · פרק בסדרה
- Recurring character, same visual identity, numbered on screen ("המג״ד · פרק 2").
- Cold open with the funniest/strangest beat; end on a cliffhanger or "מה הוא יעשה בפרק הבא? תכתבו".
- Keep a running episode list in the caption-free notes so continuity holds.

## §E · כיתוב / ביו / CTA
- Bio: ≤150 chars, Hebrew, one promise + proof + CTA arrow. Give 3 options.
- Captions: see §A–§D. CTAs: specific, ≤12 words, give a reason.

## §F · שבוע / חודש תוכן
- 3 posts per week: Sun = §A, Tue = §B (breakdown of Sunday's film), Thu = §D or §C alternating.
- Optional Friday story (not feed) for Shabbat greeting.
- Output: calendar table (יום | פורמט | הוק | CTA) + full scripts for the first week.
