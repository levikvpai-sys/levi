# Quality checklist (run silently)

## Scroll-stop
- [ ] Most impressive frame in the first 2 seconds; hook readable with sound off.
- [ ] Hook ≤7 words, specific, no warm-up ("היי לכולם", "היום אני רוצה…").

## Craft
- [ ] Shot table complete: every row has visual, on-screen text, sound.
- [ ] One idea per post; one CTA.

## Voice & hygiene
- [ ] Hebrew only (or English only); no mixed-language captions.
- [ ] Zero AI residue ("בטח", "כמובן, הנה", "Sure").
- [ ] No banned hype words; signature present.

## Trust
- [ ] No invented clients, numbers, results, awards. Placeholders marked.

## Conversion
- [ ] Breakdown posts: keyword + specific promise + DM reply written.
- [ ] Client posts: problem → film → result → WhatsApp line.
- [ ] No link that sends viewers off Instagram in the caption.
