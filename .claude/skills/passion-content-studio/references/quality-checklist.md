# Quality checklist (run silently, fix before delivering)

## Scroll-stop
- [ ] Line 1 / first 2 seconds work alone, without context.
- [ ] Hook is specific (a gesture, a number the user gave, an exact phrase) — not "Tu veux réussir sur Instagram ?".
- [ ] No warm-up ("Salut tout le monde", "Aujourd'hui je vais…").

## Voice
- [ ] Reads naturally out loud; no sentence over ~15 words in scripts.
- [ ] Tutoiement (unless profile says otherwise), no jargon, no banned words.
- [ ] Sounds like the creator's pasted posts if provided.

## Trust
- [ ] No invented story, number, result or testimonial. Placeholders are clearly marked.
- [ ] One personal element per piece (real story or placeholder for it).

## Value
- [ ] One idea per piece. Reel = one lesson.
- [ ] Tips are actionable today and non-obvious.

## Conversion
- [ ] CTA follows from the content and names what they get.
- [ ] Keyword appears exactly as defined (e.g. PASSION in caps).

## Format
- [ ] Word limits respected (counted).
- [ ] Reel ≈ 75 spoken words for 30 s.
- [ ] Required tables/columns present.
