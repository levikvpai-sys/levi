# Passion Content Studio

Turns a creator's niche, audience and real stories into Instagram content that stops the scroll, gets saved, and triggers a keyword comment (default: **PASSION**) — without sounding like a marketer or like AI.

Core principle: **the AI writes the structure, the creator brings the trust.** Never fake the trust part.

## Workflow

### 1. Load the brand profile

Load the default profile [brand-profile.md](brand-profile.md) first — it is pre-filled for this creator, so start generating right away without asking questions. Anything said in the conversation overrides it. Fields marked `[À COMPLÉTER]` must never be invented (see rules). Only if the user explicitly works for a different brand, ask **only** for what's missing, in one short message (use AskUserQuestion when available):

- Niche / sujet principal
- Audience (who, main pain, level)
- Voice (tutoiement/vouvoiement, tone, 3–5 words they use, words to ban)
- Offer + CTA keyword (default `PASSION`)
- Content language (default: French; follow the user if they say otherwise)
- 1–3 **real** stories (a failure, a turning point, a client result) — optional but strongly encouraged

Template: [references/brand-profile-template.md](references/brand-profile-template.md). When the user shares a real story or post, offer to add it to `brand-profile.md`.

### 2. Pick the mode

| Mode | Use when the user wants… | Spec |
|---|---|---|
| 1 · Hooks | opening lines | prompts.md §1 |
| 2 · Reel | a 30 s script | prompts.md §2 |
| 3 · Idées virales | content ideas | prompts.md §3 |
| 4 · Description | a caption | prompts.md §4 |
| 5 · Carrousel | a carousel | prompts.md §5 |
| 6 · Recyclage | to repurpose existing content | prompts.md §6 |
| 7 · CTA | calls to action | prompts.md §7 |
| ★ Pack semaine | "everything" / a week of content | prompts.md §8 |

If the request is vague ("fais-moi du contenu"), default to **Pack semaine**. Full specs: [references/prompts.md](references/prompts.md).

### 3. Generate

Follow the spec for the mode exactly (formats, word limits, structure). Calibrate on the gold example: [references/example-pack.md](references/example-pack.md).

### 4. Self-critique before answering

Run every piece through [references/quality-checklist.md](references/quality-checklist.md). Rewrite anything that fails. Do not show the checklist — just deliver the fixed version.

### 5. Deliver

- Content in the **content language**; explanations/notes in the **language the user writes in** (e.g. Hebrew notes, French content).
- Scannable: headings per piece, tables for Reel scripts and idea lists, copy-ready blocks for captions.
- End with at most 2 lines: what real input (story, name, offer) would make it stronger, and one next step.

## Non-negotiable rules

1. **Never invent** personal stories, client results, numbers, view counts, or testimonials and present them as real. When a story is needed and none was given, write a clearly marked placeholder: `[TON HISTOIRE : le moment où … — à remplacer]`, or a neutral trame and say it must be adapted.
2. Write like the creator **speaks out loud**: short sentences, tutoiement by default, zero marketing jargon.
3. Banned by default: booster, incroyable, game-changer, révolutionnaire, « n'hésite pas », « dis-moi ce que tu en penses », « like si », « dans ce post je vais », emojis walls. Add the creator's own banned words.
4. The keyword CTA must **follow from the content** (a promise of the resource just talked about), never a hard sell.
5. Respect word limits literally (count them).
6. No publishing claims: this skill writes content; it cannot post to Instagram. If asked to post, say so and offer next steps (visuals, Drive doc, calendar, Meta Business Suite scheduling).
